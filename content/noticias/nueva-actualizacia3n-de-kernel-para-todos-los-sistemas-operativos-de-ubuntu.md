**Canonical** anunció ayer, 29 de junio, en un informe de seguridad, la disponibilidad de nuevas actualizaciones de kernel para los sistemas operativos Ubuntu 12.04 LTS (Precise Pangolin), Ubuntu 11.10 (Oneiric Ocelot), Ubuntu 11.04 (Natty Narwhal), Ubuntu 10.04 LTS (Lucid Lynx) y Ubuntu 8.04 LTS (Hardy Heron), que corrigen tres importantes vulnerabilidades de seguridad descubiertas por varios desarrolladores en los paquetes del kernel de Linux.


Las vulnerabilidades afectan los kernels de Ubuntu 12.04 LTS, Ubuntu 11.10, Ubuntu 11.04, Ubuntu 10.04 LTS y 8.04 LTS. Pueden ingresar al siguiente link y chequear las vulnerabilidades que afectan tu sistema y esto tambien afectan a otros sistemas operativos GNU/Linux [http://www.ubuntu.com/usn/](http://www.ubuntu.com/usn/)

Los fallos de seguridad pueden corregirse actualizando tu sistema ahora. Para aplicar la actualización, ejecuta la aplicación Update Manager o echa un vistazo a algunas instrucciones detalladas: [https://wiki.ubuntu.com/Security/Upgrades](https://wiki.ubuntu.com/Security/Upgrades).

No olvides reiniciar tu computador tras terminar la actualización.
